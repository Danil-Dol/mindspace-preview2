# Предпросмотр: Вики и Тесты

Структура как в wwwroot основного проекта: css, fonts, img, js, Wiki, Tests + wiki.html, tests.html.
index.html — стартовая страница; остальные html в корне — заглушки «раздел недоступен».

Обновить вики/тесты: заменить папки Wiki/ и Tests/ (и js/wiki.js, js/tests.js, js/Test/) файлами из основного проекта, затем git add -A, commit, push.
